プライバシーポリシー (Privacy Policy)

最終更新日: 2024年7月29日

1. はじめに

このプライバシーポリシーは、「CaleShift」（以下、「本サービス」といいます）が、ユーザーの個人情報をどのように収集、利用、保護するかについて説明するものです。本サービスをご利用いただく前に、このプライバシーポリシーをよくお読みください。

2. 収集する情報

本サービスは、以下の情報を収集します。 LINEアカウント情報: ユーザーの内部識別子 (LINE User ID) ユーザーの表示名 （本サービスは、上記以外のLINEプロフィール情報（ステータスメッセージ、プロフィール画像など）にはアクセスしません。） Googleアカウント情報: 本サービスがユーザーのGoogleカレンダーにアクセスするための認証情報（OAuth 2.0 アクセストークンおよびリフレッシュトークン）。 （本サービスは、ユーザーのパスワードや、カレンダー以外のGoogleアカウント情報にはアクセスしません。） ユーザーが提供する情報: LINEを通じて送信されたシフト表の画像。 LIFFアプリを通じて設定された勤務場所の情報、シフト表の解釈ルール、およびシフト表上のご自身の氏名。 LIFFアプリを通じて編集・確定されたシフト情報（日付、開始時刻、終了時刻など）。

3. 情報の利用目的

収集した情報は、以下の目的のために利用します。 本サービスの提供、維持、改善のため。 LINEから送信されたシフト表画像を解析し、シフト情報を抽出するため。 ユーザーの指示に基づき、抽出または入力されたシフト情報をユーザー自身のGoogleカレンダーにイベントとして登録するため。 ユーザーアカウントの管理と、本サービスに関するサポートを提供するため。 本サービスの利用状況を分析し、サービス向上に役立てるため。

4. 情報の第三者への提供

本サービスは、以下の場合を除き、ユーザーの個人情報を第三者に提供または開示しません。 ユーザー本人の同意がある場合。 法令に基づき開示が求められた場合。 人の生命、身体または財産の保護のために必要がある場合であって、本人の同意を得ることが困難であるとき。

5. 情報の管理とセキュリティ

本サービスは、収集した情報の紛失、盗用、悪用、不正アクセス、開示、改ざん、および破壊を防ぐための合理的な物理的、技術的、管理上の対策を講じています。Googleアカウントの認証情報は暗号化されたデータベース（Google Cloud Firestore）に安全に保管されます。

6. Google Calendar APIの利用

本サービスは、Google Calendar APIを利用して、ユーザーのカレンダーにシフト情報を登録します。本サービスは、ユーザーから許可されたスコープ（https://www.googleapis.com/auth/calendar.events）の範囲内でのみカレンダーにアクセスし、シフト情報の登録、更新、削除以外の目的でカレンダー情報を読み取ったり、変更したりすることはありません。 本サービスのGoogle APIの利用は、Google API Services User Data Policy（限定的な利用に関する要件を含みます）に準拠しています。

7. プライバシーポリシーの変更

本サービスは、必要に応じてこのプライバシーポリシーを変更することがあります。変更があった場合は、本ページにて通知します。定期的にご確認くださいますようお願いいたします。
